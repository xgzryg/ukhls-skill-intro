ukhls-skill从研究问题到投稿稿件

一篇 UKHLS 论文怎样做出来

从一个研究问题出发，逐步确认现有证据、可用的测量与分析条件。每个阶段保留可供下一步复用的成果。

文献检索与查新

拟定检索式，筛选最接近的论文。对照人群、波次、测量和方法，记录检索日期、关键证据及可能的研究增量。

辅助选题与研究设计

把研究兴趣收敛成可回答的问题。核对目标人群、暴露、结局、时间顺序与字段可得性，再形成分析及表图计划。

字段清洗与分析表构建

核对编码、缺失和测量单位，按实际观察单位连接人员、家庭或跨波次记录。保留字段来源、纳排口径及样本流。

统计分析与模型诊断

根据研究问题核对权重、重复测量和失访。可实施调查加权回归、Cox、混合模型及 GEE 等路线，保存未舍入估计与适用诊断。

科研图表与结果复核

用实际估计、分母和置信区间构图，检查效应方向、参考线与图表可读性。提供森林图、样本流程图、诊断图及可编辑表格。

手稿写作、优化与投稿

依据当前结果撰写方法、结果与讨论。精炼重复辩解与限定语，保留证据边界，整理投稿信、补充材料和审稿回复。

描述当前任务后，ukhls-skill 识别研究阶段，优先调用相应的内置工作流程。新课题从选题与设计进入，已有项目承接已确认的计划、有效结果和当前稿。

快速开始

准备技能和运行环境。给出一项研究兴趣、已有方案或需要完成的成果即可开始。

  1. 安装技能

    取得 ukhls-skill 技能文件夹后，将它安装到支持 Skills 的宿主，再打开新会话。

  2. 准备并核查环境

    在技能目录运行对应系统的安装入口。安装器会检查 Python、R 和所需依赖。环境准备通过后运行 doctor 核查常规入口。

  3. 创建或接续课题

    在会话调用 $ukhls-skill，给出项目位置、当前问题和所需成果。新课题按阶段搭建工作区，已有课题从当前材料接续。

在技能目录运行

Windows PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
.\ukhls.ps1 doctor
macOS / Linux
bash ./install.sh
bash ./ukhls.sh doctor

读取安装报告中的 ready 状态，确认对应环境能够运行。

新项目怎样组织

项目按研究阶段建立目录，保留审阅过的方案、执行代码、图表来源和当前稿。长任务按实际阶段记录进度，后续可以从有效结果接着做。

示例课题 · 体力活动变化与后续心理健康

先查新并验证可行性查最相近的纵向研究，确认体力活动与心理健康的测量波次，以及暴露先于结局的观察窗口。

把方案落实到分析核对重复测量、纳排、变量编码、权重及缺失处理。整理面板并依预定方案拟合，保存样本流和模型诊断。

让结果进入论文用未舍入结果制作效应图及表格。写清测量、时间、分析口径和适用范围，按期刊要求整理稿件。

从零做课题

使用 $ukhls-skill，围绕我的研究问题开展从选题到投稿准备的全流程。先查新、核实字段与波次并建立项目，再按确认的方案清洗、分析、出图和写稿。

查新与选题

使用 $ukhls-skill，检索与我的研究兴趣最接近的 UKHLS 论文。比较人群、波次、变量定义和分析方法，给出有文献依据且字段可行的选题。

查字段与清洗

使用 $ukhls-skill，先核对暴露、结局和协变量的定义、可用波次及缺失编码。按现有纳排计划整理分析表，并记录各阶段人数和清洗规则。

拟合模型

使用 $ukhls-skill，按我已确认的方案核对样本、时间定义和权重。拟合指定模型，输出未舍入的估计值、95% 置信区间、入模人数及适用的模型诊断。

生成图表

使用 $ukhls-skill，把当前模型结果做成森林图。核对效应尺度、参考线及区间，统一投稿样式，输出 PDF、可复现绘图脚本和图注。

写作与修订

使用 $ukhls-skill，根据当前表图与已核实的文献优化手稿。减少重复的防御性表述，保留必要限定和修改依据，并核对正文与图表。
在宿主会话中粘贴指令

论文交付包含什么

研究依据检索及查新记录、选题依据、研究方案、字段字典和明确的纳排口径。

可复现分析清洗与模型脚本、样本流、未舍入结果、诊断、图表及图注。

稿件与投稿文件当前稿、图表和引用核对，按需整理投稿信、亮点、补充材料及修订说明。

数据访问与成果发表

  1. 先申请访问。在 UK Data Service 查找适合研究的 Understanding Society 版本，按其访问等级注册，接受许可条款并完成适用的申请或审批。
  2. 按授权范围使用。遵循具体项目的用途、存储、处理环境及共享限制，保护受访者隐私。
  3. 核对发表条件。投稿或公开表图前，按许可完成适用的披露检查。须经发表许可或输出审查的成果，获批后再公开。按目录条目引用具体版本、DOI 及致谢。
